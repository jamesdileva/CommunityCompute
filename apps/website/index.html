Turn your PC's idle time into useful compute.

CommunityCompute pools spare CPU and GPU cycles from ordinary home computers. Your machine picks up small, self-contained work units while it is idle, verifies them, and earns contribution credit — you keep control the whole time.

This is a controlled, invited beta: you need an enrollment token from the operator. See how to join.

How it works

  1. Install the worker and scan your hardware — it never touches your files and opens no inbound ports.
  2. Set your limits — idle-only, CPU/GPU caps, a temperature ceiling, hours, and battery rules.
  3. Join with a single-use enrollment token from the operator. One token, one machine.
  4. Earn credit — every verified work unit adds to your contribution balance, visible in your node's dashboard.

Work units are deterministic and independently verified, so the network never has to trust a contributor's result blindly.

From source

Have Python 3.12+? Clone the repo and run the worker directly.

git clone <repo>
python apps/worker/worker/main.py --setup

Join in four steps

  1. Get a token. The operator sends you a single-use enrollment token over a trusted channel.
  2. Run setup. Answer a few questions (all have safe defaults) — coordinator URL, token, contribution limits. 
    worker.exe --setup
  3. Enroll. Exchange the token for this machine's credential, then start contributing. 
    worker.exe --enroll <token> --coordinator-url http://<coordinator>:8000
worker.exe --coordinator-url http://<coordinator>:8000 --loop
  4. Watch your node. worker.exe --status shows whether you are contributing; the dashboard shows your contribution and credit balance.

Pause any time from the tray, worker.exe --pause, or the dashboard. Uninstall with scripts/uninstall_worker.ps1.
